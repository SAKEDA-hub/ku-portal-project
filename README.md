## Установка

**Windows.** Скачайте и запустите `KU-Portal-Setup.exe`. Если появится окно SmartScreen «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Android.** Откройте ссылку на `KU-Portal.apk` на телефоне, скачайте и откройте файл. Телефон попросит разрешить установку из этого источника — разрешите и вернитесь назад. Если при обновлении пишет «конфликт пакетов» — удалите старую версию и установите новую (данные хранятся на сайте и не пропадут).

**macOS.** Откройте `.dmg` и перетащите KU Portal в «Программы». При первом запуске: правый клик по приложению → «Открыть» → «Открыть».
